# Rule 1 [must] - 給人讀的文字一律用繁體中文與台灣用語
- 敘述、description、summary、註解、UI 文字、錯誤訊息與假資料,一律用繁體中文(正體字)
- 用台灣用語:資料(不是數據)、程式(不是程序)、伺服器(不是服務器)、預設(不是默認)、檔案(不是文件)、介面(不是接口)、使用者(不是用戶)、網路(不是網絡)、記憶體(不是內存)、設定(不是設置)、訊息(不是信息)、支援(不是支持)、登入(不是登錄)
- 識別字、程式碼、指令、欄位名稱、專有名詞與技術術語(如 Ollama、T4、OAuth、compute units)保留原文
- 為什麼:使用者在台灣,讀的是繁體中文;混進簡體字或大陸用語,讀的人要自己轉換,也看不出產出物是不是被機器直接搬過來沒人看過

## good example
- OpenAPI 的 description **用正體字與台灣用語**(伺服器、預設、使用者),路徑與欄位名稱保留原文
```yaml
/sessions:
  post:
    summary: 開啟工作階段
    description: 在 Colab 配置一台 T4 執行環境;已有工作階段時,伺服器回傳 409,預設不另開新的。
    responses:
      '409':
        description: 使用者已有開啟中或就緒的工作階段
```

## bad example
- 同一段,但**混進簡體字與大陸用語**(会话、服务器、默认、用户)
```yaml
/sessions:
  post:
    summary: 开启会话
    description: 在 Colab 配置一台 T4 运行环境;已有会话时,服务器返回 409,默认不另开新的。
    responses:
      '409':
        description: 用户已有开启中或就绪的会话
```

## good example
- 邊界:UI 假資料裡的模型名稱與單位是專有名詞,**保留原文**;說明文字仍用繁體中文
```js
const models = [
  { name: "qwen2.5:7b", size: "4.7 GB", note: "已存在雲端硬碟" },
];
```

## bad example
- 邊界:為了「全中文」**把專有名詞也翻掉**;使用者拿這個名稱去 Ollama 找不到模型
```js
const models = [
  { name: "通義千問2.5:7b", size: "4.7 吉位元組", note: "已存在雲端硬碟" },
];
```
