## 欄位說明

- **經過時間**:這個階段從開始到下一階段開始的牆鐘時間,包含等使用者回覆、等 subagent、跑測試的時間。
- **輸入**:沒有命中快取的輸入 token;**快取寫入**、**快取讀取**:prompt cache 的寫入與讀取;**輸出**:模型產生的 token。
- **合計**:四項相加。快取讀取通常占大宗,它的單價遠低於一般輸入。
- **實際作業**:相鄰兩筆紀錄間隔不超過 10 分鐘的時間加總;超過 10 分鐘視為閒置(等使用者、等 subagent、被續派前的空檔)。主 agent 只計模型回應的時間點,subagent 計它 transcript 的每一筆。
- **起訖跨度**:subagent 第一筆到最後一筆紀錄的時間;被 SendMessage 續派過的會包含中間的閒置。
- **呼叫數**:模型回應的次數(一則 assistant 訊息算一次)。

## 限制

- 經過時間是牆鐘時間,不是模型實際運算時間;夜間無人時 subagent 在跑,主 agent 在等。
- 主對話歷經多次脈絡壓縮,壓縮本身的模型呼叫若沒有寫進 transcript,就不在統計內。
- 平行的 subagent 時間會重疊,各自的耗時相加會大於階段的經過時間。
- 還在跑的 subagent 只算到產生本文件的那一刻。
